# User Journeys

> **Version**: 1.0.0  
> **Last Updated**: 2026-07-30  
> **Status**: Active  
> **Owner**: Product Manager

---

## Purpose

Complete user journey maps for all roles.

## Scope

Lifecycle for every user type: entry, goals, tasks, decisions, errors, success, exit.

## Audience

Product managers, UX designers, and developers.

---

The complete user journey maps are maintained in the governance documentation:

→ **[../governance/user-journeys.md](../governance/user-journeys.md)**

This document covers journeys for:
- Platform Owner (super_admin)
- Organization Administrator (org_admin)
- Data Analyst (data_analyst)
- Researcher (researcher)
- Data Entry Officer (data_entry_officer)
- Viewer (viewer)
- Personal Workspace User
- Department Manager (dept_manager)
- Auditor (auditor)

Each journey includes: entry point, goals, journey diagram, screen-by-screen flow, decision points, error handling, success outcomes, exit points, and estimated time-to-value.
