## Purpose

Guide for Personal Workspace users.

## Scope

Personal workspace features and limitations.

## Audience

Individual users without an organization.

---

## 1. Overview

A Personal Workspace is for individual users who want to explore the platform without an organization. You get a private workspace with limited features.

## 2. Registration

Sign up at `/signup` and select "Personal" mode. You get:
- `viewer` role
- Personal workspace
- No organization affiliation

## 3. Key Capabilities

- View dashboards (if shared)
- View reports (if shared)
- Update profile and appearance settings
- Explore the platform

## 4. Limitations

- Cannot invite other users
- Cannot create organizations
- Limited permissions (viewer role)
- No access to org-level features
- No ETL pipelines or workflows

## 5. Upgrading

To access full features, you can:

### Create an Organization
1. Navigate to Settings
2. Create a new organization
3. Become the org admin
4. Invite team members

### Join an Organization
1. Receive an invitation link from an org admin
2. Navigate to the invitation link
3. Accept with matching email
4. Get role assigned by the inviter
