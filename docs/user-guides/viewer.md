## Purpose

Guide for Viewers (viewer role).

## Scope

Read-only access to dashboards and reports.

## Audience

Viewers (executives, stakeholders, read-only users).

---

## 1. Overview

As a Viewer, you have read-only access to dashboards and reports within your organization. You cannot create, edit, or delete data.

## 2. Key Capabilities

- View dashboards
- View reports
- View KPIs and analytics
- Export reports (if `reports.export` permission granted)

## 3. Viewing Dashboards

1. Navigate to Analytics
2. Select a dashboard from the list
3. View charts, KPIs, and tables
4. Use filters and drill-downs (if available)

## 4. Viewing Reports

1. Navigate to Reports
2. Select a report
3. View report content
4. Export if permitted (PDF, CSV, Excel)

## 5. What You Cannot Do

- Upload datasets
- Create or edit dashboards
- Generate reports
- Manage users
- Access settings (except profile and appearance)
