## Purpose

Guide for Data Analysts (data_analyst role).

## Scope

Analytics, dashboards, reports, and AI assistant.

## Audience

Data analysts.

---

## 1. Overview

As a Data Analyst, you create dashboards, generate reports, analyze data, and use the AI assistant for insights.

## 2. Key Capabilities

- Upload and manage datasets
- Create and edit dashboards
- Generate and export reports
- Use AI analytics assistant
- Run ML predictions
- View analytics and KPIs

## 3. Dataset Upload

1. Navigate to Datasets
2. Click "Upload Dataset"
3. Select CSV or Excel file
4. File is parsed and stored
5. View dataset details and columns

## 4. Dashboard Creation

1. Navigate to Analytics
2. Click "Create Dashboard"
3. Select data source
4. Add widgets (KPI cards, charts, tables)
5. Configure each widget
6. Save dashboard

## 5. Report Generation

1. Navigate to Reports
2. Click "Generate Report"
3. Select data source and sections
4. Generate
5. Export as PDF, CSV, or Excel

## 6. AI Assistant

Navigate to `/ai` to use the AI analytics assistant:
- Ask questions about your data in natural language
- Get AI-generated insights and summaries
- Request report drafts
