## Purpose

Guide for Researchers (researcher role).

## Scope

Research data management, statistical analysis, and publication-ready reports.

## Audience

Researchers.

---

## 1. Overview

As a Researcher, you upload research datasets, run statistical analysis, apply ML models, and generate publication-ready reports.

## 2. Key Capabilities

- Upload research datasets (CSV, Excel)
- View and manage datasets
- Run statistical analysis via Analytics Studio
- Apply ML models to research data
- Generate and export publication-ready reports
- Use AI assistant for data exploration

## 3. Research Workflow

1. Upload research data (survey responses, experimental data)
2. Explore data in Analytics Studio
3. Run statistical analysis (descriptive, inferential)
4. Apply ML models if needed
5. Generate publication-ready report
6. Export as PDF

## 4. Research Studio

Navigate to `/studios` → Research for research-specific tools and templates.

## 5. AI Assistant

Use the AI assistant for:
- Data exploration questions
- Statistical interpretation
- Report drafting
- Trend identification
