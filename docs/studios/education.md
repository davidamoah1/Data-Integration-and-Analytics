## Purpose

Document the Education Studio for educational analytics.

## Scope

Education-specific features and data types.

## Audience

Education analysts and product managers.

---

## 1. Overview

The Education Studio provides analytics for educational institutions, including student performance, enrollment trends, and curriculum effectiveness.

## 2. Use Cases

- Student performance tracking
- Enrollment trend analysis
- Curriculum effectiveness
- Attendance pattern analysis
- Graduation rate analytics

## 3. Data Types

- Student records (FERPA considerations)
- Grade histories
- Attendance records
- Enrollment data
- Assessment scores

## 4. Access

- Route: `/studios` → Education card
- Permission: `dashboard.view` (minimum)
- Org-scoped: All data isolated by organization
