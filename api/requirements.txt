# Dependencies for the Vercel serverless API function (api/index.py).
#
# Vercel's Python builder uses the nearest requirements.txt to the function
# entrypoint, so this file — NOT the root requirements.txt — determines what
# gets bundled into the deployed function.
#
# IMPORTANT: Vercel serverless functions have a 250MB bundle limit.
# Heavy packages (pandas, numpy, scipy, scikit-learn, statsmodels, joblib,
# Pillow, openpyxl, fpdf2) are excluded because they push the bundle past
# the limit and are not needed for core API operations (auth, signup, CRUD).
# Code paths that use them handle ImportError gracefully or are not reachable
# on Vercel.
# Also excluded (same reasons as before):
#   - streamlit / plotly: only used by dashboard/ (standalone Streamlit app)
#   - PyMuPDF / pytesseract: OCR requires system Tesseract binary
#   - pypdf: lazy-imported with ImportError fallback
#   - python-pptx: lazy-imported with JSON-export fallback
#   - python-docx: not imported anywhere in the codebase
